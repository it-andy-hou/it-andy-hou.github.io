📥 待我审批面板

页面加载后约 1 秒自动抓取数据，右下角绿色按钮显示待审条数。

  • 自动汇总：从 EBOOS 接口并发拉取所有待审批流程，双接口数据自动去重合并，确保不遗漏
  • 等待时长计算：精确显示流程送达至今的等待时间（天/小时/分钟），橙色高亮超时流程
  • 快速跳转：点击条目标题直接在新标签页打开对应流程详情页，无需手动导航
  • 申请人统计：展示申请人信息，便于按优先级处理审批

📊 我的流程看板

蓝色按钮显示在途流程总数，面板分两部分：阻塞分布统计 + 在途流程清单。

  • 阻塞分布 Top 10：统计各审批人手中积压的流程数量，数量最多的排在最前，一眼识别卡单关键节点
  • 在途流程清单：列出所有发起中的在途流程，显示当前处理人
  • 上步完成信息：异步加载每条流程的审批日志，展示上一步完成人及完成时间，方便判断推进状态
  • 催办功能：对阻塞超时的流程可直接发起催办，调用系统催办接口

⚙️ 数据处理机制

  • 三路 API 并发：同时调用「我创建」「待我审批」「全部流程」三个接口，每路取前 100 条，互为补充
  • 去重合并策略：以 fdId 为唯一键对双接口数据去重，优先保留待审批接口的原始数据
  • 状态过滤：只展示「待审」状态记录，已完成/已撤回等状态自动过滤
  • 审批日志异步加载：每条流程的上步完成信息通过独立接口加载，间隔 300ms 依次请求，避免触发限流
  • 防缓存机制：每次请求附带随机参数，确保获取最新数据

🚀 安装与使用

安装步骤

  1. 浏览器安装 Tampermonkey 扩展
  2. 打开管理面板 → 新建脚本
  3. 粘贴脚本内容并保存
  4. 访问内部审批流程系统自动生效

注意事项

  • • 依赖浏览器登录态（Cookie）
  • • 每次只抓取前 100 条流程
  • • 仅在顶层窗口运行，iframe 内自动跳过
  • • 刷新页面可重新加载最新数据
