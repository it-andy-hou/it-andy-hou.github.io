任务看板 Task Board

面向个人运维日常工作管理打造的轻量级看板工具。三栏式任务流转（待办/进行中/已完成），内置 AI 驱动的日报周报自动生成，以及 Gemini + 企业微信 Webhook 的智能推送，让工作进展实时可见、汇报高效。

📋 三栏看板管理

采用经典三栏看板布局，任务可通过拖拽在「待办 → 进行中 → 已完成」之间流转，直观反映工作状态。

📝 待办事项
  • • 任务池 / 明日工作计划
  • • 按项目、类型筛选
  • • 支持优先级/工时/进度/截止日期排序
🚀 进行中
  • • 今日工作总结来源
  • • 支持📌置顶，控制日报顺序
  • • 显示「今日推进事项」字段
✅ 已完成
  • • 可折叠区域，保持界面简洁
  • • 记录完成时间，用于周报统计
  • • 支持归档到独立 JSON 文件

每个任务包含：标题、类型、所属项目、描述、优先级（高/中/低）、预计工时、实际工时、完成进度、截止日期、相关链接、今日推进事项

完整的活动日志记录：每次字段变更均自动追加到 activity_log，支持追溯

文件锁 + 原子写入：防止并发写入导致数据损坏

🤖 AI 智能推送

点击「AI 推送」，系统将进行中任务和优先级最高的待办任务发送给 Gemini 分析，AI 生成 Markdown 格式的工作播报后，通过企业微信 Webhook 推送到指定群。

工作流程
  1. 1.提取进行中任务 + Top5 待办（按优先级+截止日期排序）
  2. 2.精简任务数据（标题/类型/进度/剩余工时/今日推进）
  3. 3.携带自定义 Prompt 调用 Gemini API（走代理）
  4. 4.AI 生成结构化 Markdown 播报文本
  5. 5.直连企业微信 Webhook 推送（不走代理）
系统配置项
  • Gemini API Key
  • 代理地址（用于访问 Gemini）
  • 企业微信 Webhook URL
  • 自定义 AI Prompt 模板

配置保存于独立 config.json 文件，与任务数据分离

🔒 数据可靠性设计

文件锁机制

基于锁文件实现写入互斥，支持死锁检测（10s 自动过期强制释放），防止并发写入数据损坏

原子写入

先写临时文件，再 os.replace() 原子替换正式文件，写入中断不会产生损坏的数据文件

活动日志

每个任务维护 activity_log 数组，记录每次字段变更（时间戳/字段名/旧值/新值），完整追溯任务历史

📤 数据导出

支持将任务数据导出为标准 JSON 文件，适合直接发给 AI 工具进行深度分析或外部系统集成。

全部任务（含已完成） 活跃任务（待办 + 进行中） 仅待办任务 仅进行中任务 仅已完成任务

导出字段包含：标题、类型、项目、描述、状态、进度、工时、优先级、截止日期、活动日志等全部字段
