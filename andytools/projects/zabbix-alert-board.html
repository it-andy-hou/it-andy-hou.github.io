Zabbix 告警看板

基于 Zabbix API 打造的金融级实时告警监控看板。聚焦关注主机组的活跃告警，提供多级别统计汇总，并发查询大规模主机群，是金融证券运维团队日常值班巡检的核心工具。

技术栈：Python CGI + Zabbix API + 多线程并发  |  平台：Apache Web Server

⚡ 主机组聚焦 & 并发查询

通过配置文件指定「关注主机组」ID 列表，看板只展示这些组的告警，聚焦核心业务。使用 Python ThreadPoolExecutor 并发调用 Zabbix API，大幅缩短大规模巡检的加载时间。

配置文件结构

{

  "ZabbixUrl": "http://zabbix.xxx.com/api",

  "ApiToken": "your_api_token",

  "UpdateInterval": 60,

  "FocusedGroups": [101, 102, 105]

}

查询性能优化
  • 主机列表 / 分组信息 / 触发器三路并发查询
  • API 请求超时控制（10s），防止单点卡死
  • 查询耗时分段统计，便于定位性能瓶颈
  • 主机 ID 映射缓存，避免重复 API 调用

✨ 技术实现亮点

All-in-One CGI 架构

前端 HTML/CSS/JS 和后端 Python 逻辑合并在单个 CGI 文件中，零依赖部署，无需额外 Web 框架，在 Apache CGI 环境即可直接运行

Zabbix API 封装

封装 ZabbixAPI 类，统一处理 JSON-RPC 2.0 协议通信，支持 Token 认证，异常自动捕获降级返回 None，不影响其他数据正常展示

持续时间智能格式化

告警持续时间自动换算：秒 → 分钟 → 小时 → 天，显示「2天3小时」而非时间戳，直观反映告警持续情况

主机维护状态双源合并

维护状态优先从 trigger.hosts 字段获取，降级时从 host_map 查询，确保维护标记不遗漏，两套数据源互为补充
