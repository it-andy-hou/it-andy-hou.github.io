🖥️ 主机管理

  • Excel 批量导入/导出：支持标准模板导入（IP、端口、用户名、密码、系统名称、应用名称、机房、环境等字段），同时支持批量更新已有主机信息
  • 多维度智能筛选：按系统名称、应用名称、机房、环境联动筛选，关键字模糊搜索，筛选结果实时高亮
  • 批量连接探测：支持 Ping (ICMP) 和 SSH 端口两种探测方式，探测结果实时写入主机状态并持久化，可导出探测报告 Excel
  • 统计看板：侧边栏实时显示总主机数、在线/离线/未知分类统计
  • 批量 IP 复制：勾选主机后一键复制 IP 列表（逗号分隔）到剪贴板

📜 脚本管理

  • 脚本库统一管理：创建、编辑、删除脚本，支持脚本复制快速生成副本，更新时间倒序排列
  • 标签分类筛选：为脚本打标签，通过标签快速过滤定位目标脚本
  • Excel 批量导入/导出：脚本库整体导入导出备份，方便在不同环境间迁移
  • 执行前预览：在脚本执行选择脚本时，可直接预览脚本内容，无需跳转脚本管理页

⚡ 脚本执行 & 命令执行

  • 两种执行模式：「脚本执行」从脚本库选脚本执行；「命令执行」直接输入临时 Shell 命令，两者均支持全部批量功能
  • 主机灵活选择：多维筛选勾选 + IP 批量粘贴输入，支持自动识别并校验 IP 是否在管理列表中
  • 并发执行控制：可配置并发数与超时时间，并发批次执行，实时进度百分比展示
  • 实时日志输出：带主机 IP 前缀的彩色实时日志，自动限制 1000 行防止卡顿，支持一键复制/下载日志
  • 智能退出码处理：过滤命令（grep/awk）无匹配时退出码 1 自动识别为"执行成功，无匹配结果"，避免误报
  • sudo 执行支持：可选"使用 sudo 执行"，适配免密 sudo 配置的业务账户场景
  • 定时执行：勾选"定时执行"并设置时间，任务保存为待调度状态，到时自动触发

📦 文件上传

  • SCP/SFTP 批量分发：选择多个本地文件，批量推送到所有目标主机的指定目录
  • 文件冲突策略：支持「覆盖」「跳过」「备份后覆盖」三种策略，备份自动添加时间戳后缀
  • 路径安全校验：自动检测目标路径是否为目录，防止误操作覆盖文件；路径不存在时可配置「自动创建」或「报错中止」
  • 上传进度追踪：每台主机独立显示上传状态，实时日志展示上传过程

🕐 任务调度 & 执行记录

  • 定时任务管理：列表显示所有待执行的定时任务，实时倒计时，支持调整时间、立即执行、删除
  • 轮询调度机制：主进程每 60 秒轮询数据库，对比当前时间触发到期任务，抵抗系统时间修改和休眠唤醒，过期超 1 小时自动标记为"错过"
  • 执行历史记录：完整记录每次脚本执行、命令执行、文件上传的执行结果，支持状态筛选和任务类型筛选
  • 记录排序：最新执行记录置顶显示；脚本执行列表独立展示，不混入命令执行和文件上传记录

🔧 工程任务（多步骤编排）

将脚本执行、命令执行、文件上传三类操作编排为一个完整的自动化工程，适用于版本部署、批量变更等复杂运维场景。

  • 步骤编排：可视化拖拽排序，每步骤独立配置类型（上传/命令/脚本）、目标主机、超时时间
  • DAG 依赖关系：步骤可指定依赖前置步骤，支持串行与并行混合执行
  • 严格模式：任一步骤失败，工程立即中止，后续步骤不再执行，确保部署原子性
  • 模板复用：常用工程可保存为模板，基于模板快速创建新工程
  • 企业微信通知：执行成功/失败/中断时推送 Webhook 通知，包含步骤统计和失败详情
  • 执行历史：记录每次工程执行的详细结果，包含步骤级别的耗时与状态

🏗️ 技术架构

前端渲染层

Electron Renderer + 原生 HTML5 / CSS3 / JavaScript，无框架依赖，轻量高效

主进程逻辑层

Node.js + node-ssh，IPC 通信，任务调度器，SSH 连接管理，SCP 文件传输

数据存储层

SQLite 本地数据库，better-sqlite3，存储主机信息、脚本库、执行记录、工程任务
