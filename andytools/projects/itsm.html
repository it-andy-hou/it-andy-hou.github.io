🔍 CMDB 关键字搜索

在搜索框输入关键字后按 Enter 或点击「搜索」按钮，无需跳转 CMDB 页面。

  • 多字段模糊匹配：支持按资源名称、IP 地址、负责人姓名、所属应用等字段模糊搜索，单次返回最多 10 条结果
  • 结构化展示：每条结果清晰展示资源类型、名称、IP、负责人、所属应用等关键信息
  • Token 鉴权：自动读取浏览器 localStorage 中的 ACCESS_TOKEN 完成身份认证，无需额外登录

📥 一键下载我的信息

  • 智能关键字：搜索框有内容时以当前关键字为条件导出；搜索框为空时自动使用当前登录用户姓名作为关键字
  • Excel 格式导出：调用 ITSM 下载接口，返回 .xlsx 格式文件，自动触发浏览器下载
  • 登录态检测：自动识别返回内容类型，若返回 JSON 则判断是否登录失效并提示

📅 我的值班安排

打开工具箱时自动加载，无需手动触发。

  • 本月+下月：并发请求两个月的值班排班数据，确保提前看到下月安排
  • 过期过滤：仅展示今天及之后的值班日期，历史已过期的安排自动隐藏
  • 去重排序：多接口数据自动去重，按日期升序整洁排列
  • 姓名识别：优先从页面导航栏提取中文姓名，兜底使用 localStorage 中的 USERNAME，最多重试 15 次

📋 网络申请表单生成器

全屏覆盖层表单工具，专为网络访问权限申请流程设计，支持多规则批量生成。

  • 多规则管理：支持新增/复制/删除规则，每条规则独立配置源地址、目标地址、端口号及用途说明
  • IP 机房自动识别：内置完整的 IP 网段与机房对应表，覆盖成都西信、上海锦绣申江、333世纪大厦、东莞南方中心等 8 个机房，自动计算源/目标机房
  • 笛卡尔积展开：同规则内多个源地址与目标地址按机房分组，自动生成 源机房×目标机房 的全量组合记录
  • 端口格式化：支持逗号/换行/斜杠/空格分隔多个端口，失焦后自动统一格式
  • 预览 + 导出：生成后先预览数据表格，确认无误后导出含 ITSM 标准表头的 .xlsx 文件，可直接用于系统批量导入

🚀 安装与使用

安装步骤

  1. 浏览器安装 Tampermonkey 扩展
  2. 打开管理面板 → 新建脚本
  3. 粘贴脚本内容并保存
  4. 访问内部运维管理系统自动生效

注意事项

  • • 依赖浏览器登录 Token（ACCESS_TOKEN）
  • • Excel 导出依赖 CDN 加载的 xlsx.js
  • • 未在机房表中的 IP 显示为"未知机房"
  • • 点击背景区域或 × 关闭网络申请表单
