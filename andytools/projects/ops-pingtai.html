项目背景

在金融证券公司，传统运维面临资产散落多个系统、故障响应依赖人工、批量操作效率低下等痛点。 本项目借助 Vibe Coding 驱动，以 Go 语言构建高性能后端服务，集成多个运维场景的实用工具， 将分散的 CMDB 数据统一汇聚，并引入 AI 能力辅助故障诊断，实现从传统运维向 AIOps 的渐进式转型。

核心功能模块

CMDB 资产管理

统一管理 16 种资产类型，从服务器到云资源全覆盖。

  • Linux / Windows / 虚拟机
  • 阿里云 / 腾讯云 / 操作系统
  • ES / MongoDB / MySQL / Oracle / SQL Server / TDSQL
  • 互联网映射 / 服务器配件 / 测试环境

AI 智能诊断

通过 SSH 远程连接服务器，AI 实时分析日志与系统状态，辅助定位故障根因。

  • SSH 预设账户管理，快速接入目标服务器
  • 异步任务队列，支持多任务并发诊断
  • 任务实时查询与主动取消
  • SSH 连通性预验证，避免无效诊断

NTP 批量对时

批量检测内网服务器的 NTP 时间同步状态，快速定位时钟漂移问题。

  • 支持配置多个 NTP 服务器
  • 异步并发检测，结果实时轮询
  • 精确显示各服务器时间偏差

批量 Ping 检测

批量检测 IP 或主机名的网络连通性，快速评估网络变更影响范围。

  • 支持批量输入 IP / 主机名
  • 并发 Ping，返回延迟与丢包率
  • 任务 ID 机制，支持长任务异步查询

批量 IP 跨表查询

输入多个 IP，自动跨操作系统、阿里云、腾讯云三张资产表联合检索，明确标注未命中 IP。

  • 跨三表联合查询，一次输入全面覆盖
  • 支持去重模式，消除跨表重复记录
  • 自动标记「未找到」IP，结果完整呈现

容灾链路监控

实时查看 DSG 与英方容灾备份链路状态，快速掌握跨机房数据同步健康度。

  • DSG 备份链路状态一览
  • 英方容灾链路实时查询
  • 支持链路数据定期自动同步

Oracle ETL 定时同步

平台内置 Oracle → SQLite 全量同步引擎，将企业 CMDB（Oracle）中的资产数据定时拉取并写入本地 SQLite 镜像表， 前端所有资产查询均基于镜像表响应，实现毫秒级查询速度，同时不影响生产数据库性能。
