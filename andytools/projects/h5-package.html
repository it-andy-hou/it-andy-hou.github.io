H5 多环境打包工具

面向 H5 应用发布流程打造的多环境打包平台。支持仿真/0915测试/灰度/生产四套环境一键切换，生产环境强制二次确认保护，打包完成自动推送企业微信，将繁琐的手动打包流程标准化、可追溯化。

技术栈：Python CGI + Shell 脚本 + 企业微信 Webhook  |  平台：Apache Web Server

🌍 四套环境支持

以卡片式 UI 呈现四套打包环境，操作人员点选即可切换，无需记忆复杂参数。每套环境对应独立的打包配置和目标服务器。

仿真环境 FZ

适用于测试环境的打包，验证功能完整性

0915测试 0915

专用测试环境，用于 0915 版本测试验证

灰度环境 PRE

灰度发布环境，小流量验证上线效果

生产环境 SC

正式生产环境，全量用户访问，需谨慎操作

🛡️ 生产环境保护机制

选择生产环境（SC）时，系统启动多层保护机制，防止在高压场景下因误操作导致线上事故。

步骤一：选择警告

选中生产环境卡片后，页面立即展示黄色警告横幅「⚠️ 注意：您正在执行生产环境的打包操作，请确认这是您想要的操作。」

步骤二：弹窗确认

点击「开始打包」后弹出确认对话框，明确提示「此操作将直接影响线上环境，请务必确认！」，需主动点击「确认打包」才继续

步骤三：执行锁定

打包执行期间显示全屏加载蒙层和旋转进度指示，按钮禁用，防止重复提交，预计等待 3-5 分钟

📊 部署状态 & 历史记录

页面顶部展示最近 2 天生产部署状态，右侧记录近 10 次打包历史，让每次操作有据可查。

⚙️ 打包执行流程

前端通过 POST 请求调用后端 CGI，后端执行 Git Pull + Shell 打包脚本，全程捕获输出，结果返回前端详细展示，并写入历史记录。

1

前端触发

POST /cgi-bin/h5_package_api.py，参数 action=package&environment=sc

2

Git Pull 更新代码

拉取最新代码，stdout/stderr 分别捕获，返回前端展示 Git 输出详情

3

Shell 打包脚本执行

根据所选环境调用对应打包脚本，捕获 package_output/package_error，超时控制防止卡死

4

结果通知 & 记录

成功/失败结果推送至「佣金宝出包小分队」企业微信群，同时写入历史记录 JSON 文件

📋 打包结果详情

打包完成后弹出结果模态框，详细展示每个阶段的输出，方便快速定位问题。

🔌 API 接口设计

后端 CGI 提供 RESTful 风格的接口，前端通过 fetch() 调用，支持 CORS 跨域访问。

GET ?action=get_deployment_status 获取最近生产部署状态
GET ?action=get_history&limit=10 获取打包历史记录
POST action=package&environment=fz|0915|pre|sc 执行打包任务
