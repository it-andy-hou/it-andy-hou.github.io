Net-Probe · 灵犀

一款基于 Flutter 开发的跨平台移动端网络拨测工具，面向运维与开发人员在脱离 PC 环境时，通过手机快速验证目标服务器、API 接口及网络节点的连通性。名取自"身无彩凤双飞翼，心有灵犀一点通"——一点通，正是这款工具的核心：点即测，瞬间验证。

⚡ 拨测引擎

支持四种协议的点对点连通性验证，统一超时为 3 秒，精准排障不等待。

TCP TCP 端口拨测

建立 Socket 连接，连接成功即为"通"，连接被拒或超时判定失败。

失败提示示例：超时 / 连接被拒

HTTP/S HTTP / HTTPS 拨测

发起 GET 请求，仅 2xx 状态码视为"通"。忽略 HTTPS 证书校验（自签/过期/域名不匹配均不影响判断）。

失败提示示例：HTTP 403 / HTTP 500 / 超时

ICMP ICMP Ping 拨测

发送 ICMP Echo Request，收到响应即视为"通"，超时判定失败。

失败提示示例：超时

IPv4/v6 双栈网络控制

可强制指定 IPv4 / IPv6 / 自动，规避双栈自动 Fallback 造成的误判。

适用场景：IPv6 专线 · 容灾切换验证

📡 NODES — 节点拨测主页

  • 统计汇总区：顶部显示总节点数 / 成功数 / 失败数，实时刷新
  • 一键全测：点击"开始全部测试"按钮，并发执行所有节点（并发数 10-20，队列消费）
  • 随时停止：测试中按钮变为"停止"，点击后中止排队中的任务（执行中的等待自然完成）
  • 节点卡片：左侧展示名称 + 协议://Host:Port，右侧展示状态指示器
  • 左滑单测：对失败节点向左滑出绿色 Retry 按钮，单独重测该节点，无需重跑全部
  • 快速筛选：按状态（全部/成功/失败/等待）和协议（TCP/HTTP/ICMP/IPv4/IPv6）过滤节点列表
⬜ 等待测试（灰色） ⟳ 测试中（Loading 动画） ✓ Success + 耗时（绿色） ✗ 失败 + 错误原因（红色）

📊 STATS — 统计分析

  • 本次拨测汇总：展示当前批次各协议分布、整体成功率
  • 历史数据回溯：从本地日志文件聚合读取，展示历史成功率趋势
  • 协议分布统计：TCP / HTTP / HTTPS / ICMP 各类型节点数量及成功占比

🗒️ LOGS — 拨测日志

  • 时序日志列表：每条记录包含时间戳、节点名称、拨测结果、耗时
  • 关键字筛选：支持按节点名称或结果关键字快速过滤
  • 导出 / 清空：一键导出日志文件，或清空本地日志记录

⚙️ CONFIG — 配置管理

  • JSON 文件导入：唯一的配置导入入口，调用系统原生文件选择器，支持标准 JSON 格式
  • 智能覆盖策略：以节点 name 为唯一键，名称已存在则覆盖，不存在则追加，避免重复导入
  • 本地持久化：导入成功后自动保存，App 重启无需重新导入，内置样例数据供首次使用参考
  • 手动管理节点：支持手动添加、编辑、删除单个节点，灵活应对临时拨测需求

JSON 数据格式

[
  {
    "id": "auto-generated UUID",
    "name": "Prod API Gateway",       // 覆盖策略的唯一键
    "protocol": "https",              // tcp | http | https | icmp
    "host": "api.prod.com",
    "port": 443,
    "ip_version": "ipv4"             // ipv4 | ipv6 | auto
  }
]

🏗️ 技术架构

跨平台 UI 层

Flutter 原生渲染，一套代码同时覆盖 iOS 与 Android，流畅 60fps 体验

网络引擎层

Dart 原生 Socket + HttpClient，支持 TCP/HTTP/HTTPS/ICMP，强制 IPv4/IPv6 栈选择，忽略 SSL 证书校验

本地存储层

SharedPreferences 持久化节点配置，日志文件写入设备本地，零云端依赖，数据完全私有

✨ 设计理念

极简便携

无需复杂 UI 交互，导入即用，点即测。专为运维人员在机房、会议室等场景下的快速排障设计。

精准排障

TCP 端口级探测 + HTTP 状态码精确判断 + ICMP Ping，支持强制指定 IPv4/IPv6，规避双栈 Fallback 误判。

无侵入性

仅针对用户显式导入的节点进行点对点验证，不含任何主动扫描或探测局域网未授权设备的功能。
